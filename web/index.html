名词解释悬停虚线词也有提示
AOI（Area of Interest）
研究区。一次变化检测的空间范围，用经纬度矩形框定，界面上可以手动填、地图框选或选预置地点。
NDVI（归一化植被指数）
用近红外与红光波段按 (NIR−R)/(NIR+R) 计算，值 0.3–0.8 表示植被茂密。植被被砍伐、农田变化时 NDVI 明显下降，本平台默认用它监测植被类变化。
NDWI（归一化水体指数）
用绿光与近红外波段按 (G−NIR)/(G+NIR) 计算，大于 0 大概率是水体。适合监测湖泊退水、水面萎缩（如鄱阳湖枯水期）。
NIR / R / G
卫星传感器的三个波段：近红外（Sentinel-2 的 B08）、红光（B04）、绿光（B03）。不同地物在各波段的反射特性不同，是计算指数的原料。
双时相影像（t1 / t2）
同一地点、前后两个时间的卫星影像。t1 是「变化前」，t2 是「变化后」，变化检测就是对比这两期。
Δ（差值）
t2 的指数值减去 t1 的指数值。Δ > 0 指数上升（如植被恢复），Δ < 0 指数下降（如植被退化）。
Otsu（大津法）
一种自动寻找最佳分割阈值的经典算法：对差值 Δ 的直方图自动算出阈值 T，无需人工设定。平台默认用它，也可在「高级选项」手动覆盖。
差值法 / 回归法
两种检测策略。差值法直接用 Δ 找阈值，简单直接；回归法先拟合两期指数的整体关系、剔除光照或薄云造成的整体偏移，只把「偏离正常规律的残差」当变化，抗干扰更强。
增强 / 退化 / 稳定（编码 1 / 2 / 3）
像元级的三类判定结果：指数显著上升、显著下降、变化在阈值以内基本不变。0 表示 nodata（无效像元，如云、范围外），不参与统计。
变化强度五档
在三类判定基础上按 |Δ| 超过阈值 T 的倍数细分：显著退化、轻微退化、稳定、轻微改善、显著改善，回答「变得多剧烈」。
图斑（斑块）
空间上连通成片的变化像元区域。用于统计斑块数量、平均/最大面积、斑块密度等形态指标，Top10 表列出面积最大的变化地块。
地物转移矩阵
4×4 表格，回答「什么东西变成了什么」：行是 t1 的地物类别（水体/植被/裸土建成/其他），列是 t2 的类别，对角线是未变化的部分。
总体精度 OA（Overall Accuracy）
精度评价样本中判断正确的比例，越接近 1（100%）越准。
Kappa 系数
扣除随机巧合后的一致性度量：同样正确率下，类别分布越均衡 Kappa 越高。经验上 0.6 以上算可靠，越接近 1 越好。
ha（公顷）
面积单位，1 ha = 10,000 m² = 0.01 km²，界面上的变化面积均以公顷计。
GeoTIFF / GeoJSON
两种带地理坐标的成果格式：GeoTIFF 是栅格影像（QGIS/ArcGIS 可打开），GeoJSON 是矢量多边形（每个变化图斑一个面，含面积属性）。
真彩合成
用红绿蓝三个波段合成的「人眼视角」影像，图层面板里的 t1 / t2 图层即为真彩合成，用于目视对照变化专题图。
